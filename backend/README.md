# Mini Pokédex Backend

Backend NestJS para la Clase 1 de la Mini Pokédex. Expone endpoints propios bajo `/api` y consume PokéAPI desde la capa de infraestructura.

## Ejecutar

```bash
npm install
npm run start:dev
```

Endpoint principal:

```txt
GET http://localhost:3000/api/pokemon?page=1&limit=20
```
